Technical Overview

A desktop voice assistant that listens to commands, analyzes them with regex, then executes actions such as launching apps, controlling the system, and managing files — with a spoken Zira voice reply. Now powered by an AI chat model and full Arabic support.

AI Chat Model

Any unrecognized command is sent to an AI conversation model. The app calls the Hugging Face Inference API (DialoGPT-medium, free, no key) in a background thread, and falls back to a smart local reply if offline.

# AI reply with Hugging Face + local fallback def ai_reply(prompt): try: r = requests.post(HF_API, json={"inputs": prompt}, timeout=12) if r.status_code == 200: ans = r.json()[0]["generated_text"] return ans if LANG=="en" else translate_text(ans,"ar") except: pass return f"I'm Zira, your smart assistant. You said: {prompt}"

Bilingual Support

A language toggle button switches the entire UI between English and Arabic instantly. Speech recognition uses en-US or ar-SA, and the TTS engine auto-selects an Arabic voice when replying in Arabic. Translation between the two languages uses LibreTranslate with a graceful fallback.

# Toggle language and refresh all labels def toggle_language(): LANG["mode"] = "ar" if LANG["mode"]=="en" else "en" refresh_labels()
