المعمارية والوحدات

  • speech_recognition — الاستماع ومعالجة الضوضاء المحيطة.
  • pyttsx3 — محرك TTS محلي بدون إنترنت للرد.
  • CustomTkinter — واجهة سماوية بأزرار ناعمة وشعار متوهج.
  • Matplotlib — موجة صوتية حية ناعمة أثناء الرن.
  • threading — حلقة استماع في خيط منفصل حتى لا تتجمد الواجهة.
  • subprocess / os / shutil — تنفيذ أوامر النظام وإدارة الملفات.
